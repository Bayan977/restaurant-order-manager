# Restaurant Order Manager

A simple browser-based restaurant order management system built with HTML, CSS, and JavaScript. No backend or installation required — runs entirely in the browser using localStorage.

## Features

- **Menu** — View all available dishes and prices
- **Place Order** — Select items and quantities, submit an order with a confirmation summary
- **All Orders** — View, search, and update the status of all placed orders
- **Manage Menu** — Add and delete menu items (persisted in localStorage)

## How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/Bayan977/restaurant-order-manager.git
   ```
2. Open `index.html` in any browser — no server needed.

## Project Structure

```
restaurant-order-manager/
├── index.html      # App structure and pages
├── style.css       # Restaurant-themed styling
└── app.js          # All application logic
```

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript (ES6+)
- localStorage (data persistence)
